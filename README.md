# Streak Helper

Streak Helper — независимый проект команды энтузиастов: помощник для ежедневных занятий английским в Duolingo на Windows x64. Он открывает упражнения в отдельном окне, работает по расписанию и сохраняет историю подтверждённых результатов.

Сайт: [streak-helper-windows.github.io](https://streak-helper-windows.github.io/).

## Возможности

- Ежедневная проверка по московскому времени и работа в трее.
- Три способа: тренировка звуков, повторение начального урока, практика на дорожке; настраиваемый порядок и повторные попытки.
- Ручной запуск и остановка, автозапуск Windows, история и уведомления.
- Бесплатная версия с партнёрскими предложениями; добровольные переходы и необязательный Браузер в установщике.

## Статус

Последняя проверенная предварительная сборка — **0.4.23**. Рабочие функции реализованы и локально проверены; массовое публичное распространение ещё готовится. Частные EXE/установщик не подписаны сертификатом издателя. Нужны завершение проверки рекламного формата и зафиксированный полный выпускной прогон на чистой Windows. Публичного установщика в этом репозитории нет.

Автоматизация не гарантирует сохранение серии и может противоречить правилам Duolingo. Проект не является продуктом Duolingo и не одобрен этой компанией. Нужны включённый компьютер, интернет и действующий вход.
